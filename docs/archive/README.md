# 历史归档

归档目录只保存历史审计和原始性能证据，不代表当前功能、版本、测试结果或待办状态。

- `legacy-audits-2026-10/`：早期综合报告、实施记录、优化清单、旧版项目状态页面。
- `performance-raw-2026-10/`：原始 JSON、JSONL、日志、trace 和已完成测量的原始夹具。

共归档 74 个既有文件：7 个旧审计/状态页面文件，67 个性能证据和夹具。原始数据字节与原 SHA-256 保持一致；3 份 Markdown 只修正迁移后的相对链接，`run.sh` 保留既有路径修复并按新层级定位仓库。

历史材料中的绝对源码路径、旧版本名和当时的待办保留作追溯用途；绝对路径可能在其他机器上无法打开。归档的 harness 复现还需重新准备当时的脚本、fixture 和构建环境，不能直接把历史结果标为当前验收。

当前状态请看 [自动状态页](../../DEVELOPMENT_STATUS.md) 和 [当前项目报告](../CURRENT_PROJECT_REPORT.md)；历史测量摘要见 [性能基线导航](../performance/README.md)。
